# Spiral · landing page

Landing page de portfólio de um curso fictício que ensina pré-vestibulandos de ITA, IME e vestibulares militares a estudar com IA. Ela conta a história real do autor: três anos estudando do jeito comum e, no quarto, sete aprovações (ITA, IME 23º, EFOMM 23º, EAM 5º, EEAR 11º, AFA e Escola Naval).

Página estática em HTML, CSS e JavaScript puros, sem build:

- textos que se apagam com a rolagem (curva do esquecimento);
- grafo a giz em que os materiais de estudo se conectam;
- cena da lousa que vira a nova identidade;
- mapa em pixel art com o mascote andando pela trilha dos módulos;
- trilha de leitura no topo;
- tudo respeita `prefers-reduced-motion`.

**Projeto de portfólio: o curso não está à venda.** Claude e Claude Code são marcas da Anthropic. Este projeto não é afiliado, patrocinado nem endossado pela Anthropic.
